# Безопасность

Не публикуйте ссылки подписки, секреты или инструкции для эксплуатации уязвимостей в открытых Issues. Для сообщения об уязвимости используйте приватное сообщение владельцу проекта; если доступно, откройте [частное сообщение об уязвимости](https://github.com/divezh/netlane-windows/security/advisories/new).
