## WinTrustTunnel 0.4.9 — обновление подписок при открытии

- При каждом запуске Windows-приложения подписки обновляются независимо от времени предыдущего обновления. Работает также запуск сразу в трей.
- При повторном открытии скрытого или свёрнутого окна из трея подписки обновляются снова. Переключение между уже открытыми окнами не создаёт дополнительных запросов.
- Одновременные открытия используют один запрос. Если подписка уже обновляется вручную, приложение дожидается этого обновления без дублирования.
- Автоподключение при запуске начинается после завершения попытки обновления подписок. При ошибке сохраняются прежние серверы и доступен повтор обновления.
- README.md и QA.md больше не включаются в Windows-архив. Исполняемый файл, его конфигурация, engine и licenses входят в комплект. Документация доступна в репозитории.


Сборки выполнены локально, без GitHub Actions. Проверены повторные входы, свежая подписка, объединение параллельных запросов, ошибка сети с сохранением серверов и успешный повтор. Windows-архив распаковывайте целиком вместе с engine.

Дополнительно Windows-архивы прежних релизов очищены от README.md и QA.md с пересчётом SHA256; содержимое остальных файлов проверено на неизменность.
