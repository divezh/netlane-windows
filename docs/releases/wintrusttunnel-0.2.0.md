## WinTrustTunnel 0.2.0

### Windows-клиент
- Новый значок WinTrustTunnel в окне, трее и `.exe`; приложение и панель называются WinTrustTunnel.
- Переработанный интерфейс: графитовая палитра, бирюза только на главных действиях, шестерёнка настроек в шапке вместо кнопки, которая наезжала на заголовок.
- Кольцо подключения меняет цвет по состоянию: подключено, переподключение, Kill Switch, ошибка.
- Под кнопкой — время сессии и объём трафика по счётчикам VPN-адаптера.
- Настройки: переключатель HTTP/2 / HTTP/3, тумблеры Kill Switch и Anti-DPI. Маршрутизация: вкладки со счётчиками, правила в файлах `.wttrules` (старые `.rhrules` открываются).
- При переподключении виден номер попытки; трафик считается только по работающему адаптеру VPN.
- Профиль из прежних сборок переносится и перешифровывается автоматически при первом запуске.
