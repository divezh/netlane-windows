## WinTrustTunnel 0.3.0

### Windows-клиент
- Несколько серверов: каждый импорт `tt://` или TOML добавляет сервер, прежние остаются. Повторный импорт того же пользователя спрашивает «Обновить / Добавить копию».
- Название и флаг страны приходят из панели («🇳🇱 Амстердам»), их можно поменять в «Настройки → Серверы».
- Переключение сервера щелчком по карточке или из трея; при включённом VPN приложение само переподключается — один раз на серию быстрых выборов.
- Наборы правил маршрутизации, общие для всех серверов: встроенный «Весь трафик» и свои. Выбор — «Использовать» в «Настройки → Правила» или меню трея; набор виден в строке «Маршрутизация» на главном экране.
- Главный экран: отправлено / время сеанса / получено компактно сверху; статус и индикатор Kill Switch под кнопкой без яркого ореола. Название сервера, флаг, домен и транспорт — в отдельной карточке. Обновление ping — по кнопке рядом со значением; скорости загрузки и отдачи — при наведении на счётчики. Страну можно выбрать нажатием на флаг. Кнопки «Добавить» и «Вставить» расположены снизу.
- Исправлены ширина и тёмная отрисовка меню маршрутизации, обрезание карточки сервера в минимальном окне; компоновка пересчитывается при изменении размеров.
- Окно «Настройки»: Серверы · Правила · Подключение · О программе. Кнопка «Сохранить» больше не съезжает, артефактов при растягивании нет.
- Меню в трее, уведомления (обрыв, Kill Switch, ошибка, переключение), запуск вместе с Windows, автоподключение, перетаскивание `.toml` и файлов правил на окно.
- Движок держит не больше 2 одновременных соединений с сервером вместо 8: несколько TLS-соединений к одному домену — признак, по которому DPI вычисляет туннели.
- Профиль 0.2.x переносится сам: сервер и набор «Мои правила», старый файл остаётся как `profile.bin.migrated`.
