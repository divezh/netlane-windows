## WinTrustTunnel 0.2.2

### Windows-клиент
- В режиме «Только выбранное через VPN» клиент больше не показывает «Требуется внимание» при работающем туннеле. Причиной были информационные строки движка о DNS-запросах, которые в этом режиме идут напрямую; ошибкой подключения теперь считаются только строки уровня ERROR и ненулевой код выхода движка.
