## WinTrustTunnel 0.4.0

### Windows-клиент
- «Вставить» и «Добавить» принимают ссылку подписки: добавляются все локации, список обновляется сам при запуске и раз в 6 часов, вручную — «Настройки → Серверы → Обновить».
- Сменившийся пароль подхватывается, подключённый сервер переподключается один раз; исчезнувшая локация убирается после отключения.

```sh
mkdir wtt && tar -xzf trusttunnel-dev.tar.gz -C wtt && bash wtt/setup.sh
```
