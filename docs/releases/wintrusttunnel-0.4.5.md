## WinTrustTunnel 0.4.5

### Windows-клиент

- **Окно снова закрывается, даже если движок VPN уже остановился.** Если движок завершился раньше окна (например, после отключения), при выходе появлялась ошибка «Канал нарушен» и приложение не закрывалось обычным способом. Теперь закрытие не зависит от состояния канала к движку.
- Проверка задержки и обновление подписки больше не пишут в журнал лишние ошибки («Этот хост неизвестен») от запросов, которые уже были прерваны по таймауту.
- Версия клиента теперь совпадает с версией релиза.
