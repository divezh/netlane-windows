## WinTrustTunnel 0.4.7

### Приложение Windows

- Обновление выбранной подписки с главного экрана: серверы, правила и DNS, время последнего обновления и повтор при ошибке.
- Наборы из подписки отображаются по имени, без суффикса «От администратора». Защита от редактирования сохраняется; для изменений можно создать личную копию.
- В списках доменов и приложений используется тёмная прокрутка вместо системной полосы Windows.
- Убрана лишняя подпись под обновлением подписки, исправлена подсказка для правил администратора.
- Проверка наличия движка до подключения с понятным сообщением при неполной распаковке архива.
