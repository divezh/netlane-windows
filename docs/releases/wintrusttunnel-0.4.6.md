## WinTrustTunnel 0.4.6

### Правила и DNS через подписку

- Клиент получает наборы и DNS по кнопке «Настройки → Серверы → Обновить» и при автоматическом обновлении подписки.
- Наборы отмечены «От администратора». Пользователь выбирает нужный набор, а личные наборы сохраняются. Для изменения администраторского набора можно создать личную копию.
- Обновлённые правила и DNS применяются при следующем подключении.

### Файлы

- `WinTrustTunnel-windows-x64.zip` — Windows-клиент 0.4.6 с поддержкой правил приложений.
- `*.sha256` — контрольные суммы архивов.
