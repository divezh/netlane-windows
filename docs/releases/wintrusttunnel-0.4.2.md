## WinTrustTunnel 0.4.2

### Windows-клиент

- Обновлены восемь состояний подключения. Кнопка отключения красная, статус подключения зелёный, основной акцент бирюзовый.
- Во время подключения и отключения индикатор движется по обводке кнопки. Kill Switch отмечается щитом.
- Без профиля кнопки добавления сервера и вставки ссылки одинакового размера. В карточке сервера обновление ping отделено от выбора сервера.
- В настройках используется тёмная полоса прокрутки. Поле DNS оформлено без светлой системной полосы.
