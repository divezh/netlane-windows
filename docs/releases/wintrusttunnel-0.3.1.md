## WinTrustTunnel 0.3.1

- Свой DNS в «Настройки → Подключение»: до восьми адресов, обычный DNS, DoT, DoH, TCP и QUIC.
- Настройка общая для серверов клиента, сохраняется через Windows DPAPI и применяется при следующем подключении. Сохранение не перезапускает работающий VPN.
- Очистка списка возвращает стандартный DNS движка. Неверные адреса, порты и дубликаты отклоняются; при ошибке записи прежний DNS сохраняется.

Для Windows 10/11 x64. Как и предыдущие версии, сборка не подписана Authenticode. Перед запуском проверьте SHA-256 архива.
