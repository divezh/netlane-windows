# Netlane 0.9.3 для Windows

Исправили ошибку подключения `File could not be opened for reading`, которая возникала, когда в пути к временной папке Windows была кириллица. После обновления Netlane можно запускать обычным ярлыком. Менять `TEMP` и `TMP` через PowerShell больше не нужно.

- `Netlane-Setup-0.9.3-x64.exe` — установщик для Windows 10/11 x64.
- `Netlane-windows-x64.zip` — переносная версия и пакет встроенного обновления. Для ручного обновления переносной версии выйдите из Netlane через трей и распакуйте архив поверх текущей папки программы.

Рядом с каждым файлом опубликованы контрольная сумма SHA-256 и отдельная подпись владельца `.sig`. Windows может показать предупреждение о неизвестном издателе установщика.
