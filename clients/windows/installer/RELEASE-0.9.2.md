# Netlane 0.9.2

- Полный EXE-установщик для Windows 10/11 x64: программа, движок и Wintun
  устанавливаются вместе, создаётся ярлык в меню «Пуск»; ярлык рабочего стола
  можно выбрать в мастере.
- Повторная установка обновляет программу; удаление через настройки Windows
  сохраняет подписки и правила.
- Мастер проверяет наличие .NET Framework 4.8 или новее. Если его нет,
  показывает ссылку Microsoft для установки.
- ZIP обновления и EXE-установщик имеют отдельные подписи владельца `.sig`.

## Скачать

- `Netlane-Setup-0.9.2-x64.exe` — обычная установка.
- `Netlane-windows-x64.zip` — portable-версия и встроенное обновление.

Подпись владельца подтверждает подлинность файла и не является
Authenticode-подписью издателя Windows. Предупреждения Windows могут сохраняться.
Самоподписанный сертификат в доверенные корневые не устанавливается.

Проверка установщика:

```powershell
openssl dgst -sha256 -verify netlane-release.pub `
    -signature Netlane-Setup-0.9.2-x64.exe.sig Netlane-Setup-0.9.2-x64.exe
```

Проверка ZIP:

```powershell
openssl dgst -sha256 -verify netlane-release.pub `
    -signature Netlane-windows-x64.zip.sig Netlane-windows-x64.zip
```

Движок — прежний TrustTunnel 1.3.0-netlane.1. Ошибка чтения временного
`session.toml`, наблюдавшаяся у пользователя с кириллицей в пути, этим выпуском
не исправляется. Встроенное обновление продолжает использовать подписанный ZIP.
